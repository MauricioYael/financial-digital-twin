Plataforma predictiva e interactiva diseñada para simular la vida financiera futura de los usuarios mediante Machine Learning, simulación estocástica e IA explicable.

---

## 🏗️ Arquitectura del Sistema

* **Frontend:** Next.js, React, Tailwind CSS, Recharts.
* **Backend API:** FastAPI (Python).
* **Base de Datos:** PostgreSQL.
* **Capa Analítica y ML:** Scikit-Learn, XGBoost, Prophet, LightGBM, NumPy, Pandas.
* **Motor de IA Generativa:** Ollama / Llama 3 / Mistral.
* **Infraestructura:** Docker.

---

## 📂 Estructura de Módulos (MVP)

1. **Open Banking Connector:** Ingesta y validación de fuentes transaccionales.
2. **Motor de Categorías:** Clasificación automática de ingresos y gastos.
3. **Motor Predictivo:** Proyección de flujo de caja y capacidad de ahorro.
4. **Simulador Financiero:** Análisis de escenarios hipotéticos (Monte Carlo).
5. **Asistente IA:** Copiloto conversacional financiero.
6. **Dashboard:** Visualización interactiva y métricas ejecutivas.
